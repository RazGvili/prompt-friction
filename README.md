# Instruction Failure Checklist

A Codex plugin with seven things to look for when reviewing how an agent is instructed to behave. It covers duplicate rules, conflicting requirements, priority, tool contracts, impossible ordering, mode changes, and false alarms.

## Install in Codex

```sh
codex plugin marketplace add RazGvili/instruction-failure-checklist
codex plugin add instruction-failure-checklist@instruction-checklists
```

Ask Codex to use the **Instruction Failure Checklist** to review the agent in your project. You can also [read the checklist directly](plugins/instruction-failure-checklist/skills/instruction-failure-checklist/SKILL.md).
